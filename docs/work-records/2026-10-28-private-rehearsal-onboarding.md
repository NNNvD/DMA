# Private rehearsal onboarding

2026-10-28, Windows/PowerShell/Python 3.11. The DM selected an existing session
starting point and authorized preparing an isolated private rehearsal.

Implemented explicit rehearsal onboarding, copy verification, guarded operator
support, selected source catalogs/room/bestiary reads, a separate local server,
rehearsal banners and explicit initial session/map selection. No real campaign
content or identities are recorded here. Snapshots and the working copy are under
the ignored local workspace; original sources remain unchanged.

The original SQL store contained no entities or documents. Existing campaign
information is in the private overlay; no bulk import or automatic acceptance was
performed. The legacy column definitions match the generated 0003 baseline after
ignoring harmless column-order differences. The first comparison correctly
withheld activation until that comparison issue was diagnosed. The verified
snapshot was reused without overwriting a running rehearsal or changing sources.

Local checks verified all selected private files, original DB logical contents,
copy integrity/foreign keys, current schema, explicit session association and
selected room lookup. Browser checks verify PRIVATE REHEARSAL labeling, the chosen
session/map, PC/NPC dossier lists and absence of unhandled JavaScript errors. An
initial startup race selected the default map; explicit preferred-map metadata
fixed it. Runtime imports point only at copied stores. Rehearsal browser resources
are restricted to local sources; external acquisition is disabled.

Automatic approval review initially **rejected the native agent launch** because selected
private campaign/GM material would be transmitted to the Codex service without
explicit destination-specific consent. It was not retried or bypassed. Local
preparation continued. The DM subsequently explicitly authorized selected private
notes, character records and GM-only room/bestiary material to the Codex service.
Native preparation, live assistance and the guided debrief then ran against the
private copy. The debrief produced private drafts; no report approval, canonical
closure or publication was performed. Story content and transcripts remain ignored.

Synthetic regressions cover material catalogs, exact citable entries, foreign
campaign rejection, ambiguous IDs, source-path isolation and existing reader,
launcher and live-panel behavior. The local rehearsal alone does not establish
full CI, human play-testing, real campaign activation or canonical closure.
