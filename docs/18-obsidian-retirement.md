# Obsidian integration retirement

The project no longer uses Obsidian as an active campaign workspace. The two
local `obsidian-abomination-vaults-vault` data folders were archived on
2026-09-02 under `local-private-overlay/archive/2026-09-02-obsidian-vault-retirement/`.

The application compatibility code and legacy export helpers remain in the
repository for now, but they should be treated as inactive. Do not recreate or
populate an Obsidian vault unless the workflow is explicitly reinstated.

The current source of truth for private campaign data is the root private
overlay described in `docs/17-private-local-campaign-bundle.md`.
